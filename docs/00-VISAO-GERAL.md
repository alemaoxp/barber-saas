# Barber SaaS

## Visão Geral

O Barber SaaS é um sistema de agendamento online para barbearias, desenvolvido com foco em simplicidade, desempenho e escalabilidade.

O objetivo inicial é entregar um MVP para ser utilizado por uma barbearia real, permitindo validar o produto o mais rápido possível.

Após a validação do MVP, o sistema evoluirá para uma plataforma SaaS (Software as a Service), permitindo que diversas barbearias utilizem o mesmo sistema através de assinaturas mensais.

---

# Objetivos do Projeto

## MVP

O MVP deverá conter:

* Landing Page
* Login do barbeiro
* Painel administrativo
* Cadastro de serviços
* Cadastro de clientes
* Cadastro de horários disponíveis
* Agendamento online
* Bloqueio automático de horários ocupados
* Calendário da agenda
* Área do cliente para realizar agendamentos

---

# Futuras Funcionalidades

Após a validação do MVP, estão previstas as seguintes evoluções:

* Pagamentos via PIX
* Integração com WhatsApp
* Programa de fidelidade
* Múltiplos barbeiros
* Dashboard com indicadores
* Assinatura mensal
* Multiempresa (SaaS)

# Filosofia do Projeto

Este projeto seguirá alguns princípios durante todo o desenvolvimento:

* Construir um MVP rapidamente.
* Manter uma arquitetura organizada desde o início.
* Adicionar complexidade apenas quando necessário.
* Documentar todas as decisões arquiteturais.
* Priorizar código limpo e de fácil manutenção.
* Trabalhar como uma software house, utilizando boas práticas e versionamento contínuo.
