# Barber SaaS

Este é um projeto monorepo para o sistema Barber SaaS, uma plataforma completa para gestão de barbearias.

## Estrutura do Projeto

```
barber-saas/
├── backend/         - Aplicação Spring Boot (API REST)
├── docs/            - Documentação do projeto
├── prompts/         - Prompts para IA/LLM
└── README.md        - Este arquivo
```

## Backend

O backend é uma aplicação Spring Boot que fornece uma API REST para o sistema.

### Tecnologias
- Java 17+
- Spring Boot 3.x
- Maven
- Docker

### Executando o Backend

```bash
cd backend
./mvnw spring-boot:run
```

## Documentação

A documentação do projeto está na pasta `docs/` e inclui:
- Visão geral do sistema
- Arquitetura
- Guias de desenvolvimento

## Prompts

A pasta `prompts/` contém templates e prompts para uso com IA/LLM no desenvolvimento do projeto.
